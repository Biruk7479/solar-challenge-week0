# Notebooks Directory

This directory contains Jupyter notebooks for exploratory data analysis (EDA) of solar radiation data from different countries.

## Notebooks:
- `benin_eda.ipynb` - EDA for Benin (Malanville) solar data
- `sierraleone_eda.ipynb` - EDA for Sierra Leone (Bumbuna) solar data
- `togo_eda.ipynb` - EDA for Togo (Dapaong) solar data

Each notebook includes:
- Summary statistics and missing value analysis
- Outlier detection and data cleaning
- Time series analysis
- Correlation analysis
- Wind and distribution analysis
- Temperature and humidity analysis
